[V1.5] 05-28-25

    Dean Functionalities:
        - [New] Added UI display for the number of Easy, Moderate, and Difficult questions available.
        - [New] Implemented answer key view functionality for the Qualifying Exam (QE).
        - [New] Deans now have the ability to change positions of all user roles within the system via a dedicated UI.

    Associate Dean Functionalities:
        - [New] Added UI display for the number of Easy, Moderate, and Difficult questions available.
        - [New] Implemented answer key view functionality for the Qualifying Exam (QE).
        - [New] Associate Deans can update the roles of Program Chairs, Instructors, and Students—limited to users within their campus.
        - [Enhanced] Associate Deans can now view only the questions relevant to their assigned campus.    

    Program Chair Functionalities:
        - [New] Added UI display for the number of Easy, Moderate, and Difficult questions available.
        - [Enhanced] Program Chairs are restricted to viewing questions only from their respective programs
        - [New] Program Chairs can update roles of Faculty and Students under their program and campus. 
        - [New] Program Chairs can approve or disapprove Faculty and Students within their program.


    Instructor Functionalities:
        - [New] Added UI display for the number of Easy, Moderate, and Difficult questions available.
        - [New] Faculty members can approve or disapprove Students under their assigned program. 

    Student Functionalities:
        - [New] Students can now submit feedback directly through the platform. 
        - [New] Added information about the following qualifying exams on the practice test instructions 

    Bug Fixes & Improvements:
        - [Fixed] Corrected subject name rendering during practice exams.     
        - [Fixed] Improved label clarity and consistency for user codes.
        - [Fixed] Associate Deans can no longer add new subjects.
