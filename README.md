# CAPS - College Assessment and Practice System

A web-based assessment platform built with Laravel (backend) and React (frontend), containerized using Docker. It supports subject/question management, qualifying exam workflows, and practice exams for students.

## Key Features
- Subject and question bank management
- Admin approval workflow for questions
- Practice exam generation and results tracking
- Role-based access for faculty, program chairs, deans, and students
- Dockerized deployment for consistent environments

## Tech Stack
- Backend: Laravel
- Frontend: React + Vite
- Database: MySQL
- Containerization: Docker / Docker Compose
